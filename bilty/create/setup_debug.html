🔧 Bilty System - Setup & Debugging

🚀 Getting Started

The bilty form requires sample data in the database to function properly.

Common Issues & Solutions:
Consignor/Consignee not fetching No party data exists. Create parties in Party section first.
Station not fetching No stations in database. Use tab "Database Setup" to add sample data.
Product details not fetching No products exist. Add sample products to database.
Freight not calculating Try refreshing the page. Enter quantity, then click outside field.
Quick Setup Steps:
  1. Go to Database Setup tab
  2. Copy SQL commands
  3. Paste into phpMyAdmin SQL tab
  4. Run the commands
  5. Refresh the bilty form
  6. Try searching for parties, stations, products
